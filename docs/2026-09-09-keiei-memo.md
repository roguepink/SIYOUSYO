## 1. ✅ 解決済み：インボイス問題は当社に影響しない

### 結論

**簡易課税のため、職人がインボイス登録していてもいなくても、当社の消費税は1円も変わらない。**

### 理由

簡易課税は納税額を「**売上税額 × みなし仕入率**」で機械的に計算する制度で、**実際の仕入を一切見ない**。したがって仕入先の登録有無は計算に入らない。

| | 本則課税 | **簡易課税（当社）** |
|---|---|---|
| 控除額の計算 | 実際に支払った仕入の消費税を集計 | 売上 × みなし仕入率 |
| 仕入先の登録有無 | 影響する | **影響しない** |
| 経過措置（80%→70%…） | 適用される | **無関係** |

### やらなくてよいこと

- 職人へのインボイス登録依頼
- 単価の見直し交渉
- 2割特例・3割特例の説明
- 経過措置の帳簿記載要件への対応
- 2031年の経過措置廃止への備え

### 参考：経過措置の最新スケジュール（本則課税の会社向け／当社には無関係）

令和8年度税制改正で**2年延長・引き下げペースが緩和**された。

| 期間 | 控除割合 |
|---|---|
| 〜2026/9/30 | 80% |
| **2026/10/1〜2028/9/30** | **70%**（新設） |
| 2028/10/1〜2030/9/30 | 50% |
| 2030/10/1〜2031/9/30 | 30% |
| 2031/10/1〜 | 廃止（0%） |

### ただし将来の注意点

- **課税売上高5,000万円の壁**：基準期間（2期前）の課税売上高が5,000万円を超えると、その2期後から自動的に本則課税へ。その時点でインボイス対応が必要になる。
  - → **売上が4,000万円台に乗ったら、職人の登録状況を整え始める**
- **大きな設備投資（車両・機械等）がある年は簡易課税が不利**。かつ簡易課税には**2年縛り**があるため、投資の2期前から税理士に相談すること。

## 2. ⚠️ 要確認：簡易課税の事業区分（年30〜50万円のインパクト）

**インボイスより金額が大きい可能性がある論点。**

### みなし仕入率

| 区分 | 率 | 内装工事での該当 |
|---|---|---|
| 第3種（建設業） | **70%** | 自社で材料を仕入れて施工 |
| 第4種 | **60%** | 材料支給の手間請け（労務中心） |

### リスク

両方の工事をやっているのに**売上を区分経理していない場合、低いほう（60%）が全体に適用される**。

**差額の試算：**

| 年間課税売上高（税抜） | 70%と60%の納税額の差 |
|---|---|
| 3,000万円 | 約 **30万円/年** |
| 4,000万円 | 約 **40万円/年** |
| 5,000万円 | 約 **50万円/年** |

計算式：売上（税抜）× 10% × (70%−60%)

### 救済ルール

**75%ルール**：1つの事業区分が全体の75%以上を占める場合、その率を全体に適用できる。材料込み工事が75%以上なら、手間請け分も含めて70%で計算可能。

### アクション

→ **税理士に確認する（下記の質問リスト参照）**。過去分について更正の請求ができる場合もある（原則5年）。

## 3. 🔴 最重要：建設業許可の失効判断について

### 現在の方針

今年は更新申請せず失効させる。500万円超の受注時に再取得する。

### 指摘した懸念

#### ① 失効した許可は復活できない

再交付の制度はなく、**「新規」で取り直すしかない**。

| | 更新 | 新規（再取得） |
|---|---|---|
| 手数料（知事許可） | 5万円 | **9万円** |
| 必要書類 | 少ない | 多い |
| 許可番号 | 維持 | **変わる** |

#### ② 時間が間に合わない

- **標準処理期間 30〜90日**（審査のみ）
- 書類準備を含めると**実質2〜4ヶ月**
- → 「仕事が来てから申請」では間に合わない
- → 元請けの発注リストから外れるリスクのほうが大きい

#### ③ 要件の証明ができなくなるリスク（最大の落とし穴）

| 要件 | 内容 | 失効後の困難さ |
|---|---|---|
| **経営業務の管理責任者** | 建設業の経営経験5年以上の常勤役員 | 許可期間中は許可通知書で証明可。失効後は**契約書・注文書・請求書・通帳を5年分**揃えて疎明が必要 |
| **専任技術者** | 資格保有 or 実務経験10年 | 父が専技だった場合、引退で不在に。実務経験10年の証明は**書類10年分**が必要 |
| **財産的基礎** | 自己資本500万円以上 or 500万円以上の資金調達能力 | **業績が厳しい時期に再申請すると落ちる可能性** |

**最悪のシナリオ**：大きな仕事の話が来る → 申請しよう → 証明資料がない／専技がいない／自己資本が足りない → **許可が取れない** → 仕事を失う

### 500万円判定の落とし穴

| ルール | 内容 |
|---|---|
| **税込で判定** | 税抜455万円で届く |
| **材料費を含む** | 注文者が材料を支給する場合も、**市場価格＋運送費を加算**して判定 |
| **分割不可** | 正当な理由なく分割しても合計額で判定 |
| **追加工事** | ← **最も危険**。当初420万→追加で510万は日常的に起きる |

→ 実務上、**税抜400万円を超える案件はすべてリスク**と考える。

### 罰則

- **3年以下の懲役 または 300万円以下の罰金**（併科あり／法人にも両罰規定）
- **罰金刑を受けると、その後5年間は建設業許可を取得できない**
- 元請け側も無許可業者への500万円超の発注は監督処分の対象 → **元請けは無許可業者を避ける**

### 提案した代替案：経費を1/5にする

維持コストの内訳：

| 項目 | 頻度 | 実費 | 行政書士に依頼した場合 |
|---|---|---|---|
| 更新手数料 | 5年に1回 | 5万円 | ＋報酬5〜10万円 |
| 決算変更届 | **毎年** | ほぼゼロ | ＋報酬3〜5万円 |
| 各種変更届 | 都度 | ほぼゼロ | ＋報酬1〜3万円 |

| | 年間コスト |
|---|---|
| 行政書士に全部依頼 | 約4〜7万円 |
| **自分でやる** | **約1万円** |

→ **「経費がかかりすぎる」の正体はおそらく行政書士報酬。自分でやれば許可を維持できる。**
→ 決算変更届は「工事経歴書＋施工金額＋決算書の転記＋納税証明書」であり、**工事別原価管理台帳から半自動生成できる**。AIで下書きを作れる作業。

### タイミング

- 更新申請は**有効期間満了日の30日前まで**（受付開始は自治体により3ヶ月前など）
- **1日でも過ぎると更新不可＝新規申請**
- → **まず許可通知書の満了日を確認する**

### それでも失効させる場合の必須対応

#### A. 証明資料の完全保全（最優先・今しかできない）

- [ ] 許可通知書（現在＋過去分すべて）
- [ ] 建設業許可申請書の副本一式
- [ ] **過去の決算変更届の控え**（工事経歴書＝実務経験の公的証明。最重要）
- [ ] 履歴事項全部証明書＋**閉鎖事項証明書**（役員在任期間の証明）
- [ ] 父・本人の資格証（施工管理技士、技能士など）
- [ ] 過去10年分の工事の契約書・注文書・請求書・入金記録
- [ ] 健康保険・厚生年金の記録（常勤性の証明）

→ すべてスキャンしてクラウド保存。**「書類のデジタル化」で最も価値の高い第一弾。**

#### B. 廃業届を必ず提出する

出さないと事業者登録が抹消扱いになり、**これまでの実績もなかったことにされる場合がある**。再取得の可能性を残すなら必須。

#### C. 専任技術者の確保

父が専技だった場合、**本人が資格を取るのが最も確実な保険**。

- 2級建築施工管理技士（仕上げ）
- 内装仕上げ施工技能士

→ 実務経験10年を書類で疎明するより、資格1枚のほうが圧倒的に楽。**経理の勉強より優先度が高い可能性がある。**

## 4. 外注費／給与の区分（簡易課税でも重要）

消費税の控除否認リスクは簡易課税により消えたが、**以下は残る**：

- **源泉徴収漏れ** → 不納付加算税・延滞税
- 社会保険・労災の問題
- 法人税上の損金性

### 判定の4ポイント

| 観点 | 外注費（○） | 給与（✕） |
|---|---|---|
| 代替性 | 他の人に代わらせてよい | 本人でなければダメ |
| 指揮監督 | 作業方法は本人の裁量 | 細かく指示 |
| 危険負担 | 完成しなければ報酬なし | 時間に応じて支払 |
| 道具・材料 | 本人が用意 | 会社が全部支給 |

### アクション

- [ ] 職人ごとに請負契約書／業務委託契約書を交わす
- [ ] **職人側から請求書を出してもらう**（会社が支払明細を作るのは給与的）
- [ ] 「日当×日数」ではなく**工事単位・出来高での請負**にする
- [ ] 道具は本人持ち（貸与する場合はその旨を整理）

→ **代替わりのタイミングは、契約を結び直す自然な機会。**

## 6. 事業承継：最優先事項

### 母の経理ノウハウの記録（最優先・今しかできない）

3人の会社で最も失われやすい資産。マニュアル化されていない判断（「この取引先はこう処理する」等）は、**失われると税理士でも復元できない**。

**手順：**

1. 母が経理作業をするところを**スマホで録音**
2. 「何をしているか、なぜそうするか」を口で説明してもらう
3. 録音を文字起こし → **AIに手順書化させる**
4. 月次・年次のカレンダーに落とす

→ **今年中に実施する。**

### 簡易課税は引き継ぎに有利

| | 本則課税 | 簡易課税 |
|---|---|---|
| 仕入・経費の消費税区分 | 1件ずつ判定が必要 | **不要** |
| インボイスの確認 | 必要 | 不要 |
| 売上の区分 | 税率区分のみ | 税率＋**事業区分** |
| 引き継ぎの難易度 | 高い | **低い** |

→ 論点が「売上の事業区分」だけに絞れる。一人で引き継ぐ立場としては追い風。

## 7. AI活用の方向性

### 大原則：会計ソフト（TKC）は変えない

| 理由 | 内容 |
|---|---|
| 税理士とセット | TKCは会員事務所とセットの仕組み。変えると**税理士事務所ごと変える**話になる |
| 記帳適時性証明書 | **金融機関の融資審査で有利**。事業承継期は借入が絡むため価値が大きい |
| 月次巡回監査 | 現在の運用そのもの。信頼性が高い |

### AIを入れる場所：「TKCの手前」と「TKCが扱わない領域」

TKCは**財務会計**（決算書と申告のため）。内装工事業の経営に必要な**工事別の粗利管理**は扱わない。

#### ★ 本丸：工事別原価管理

```
現場ごとに：
  見積金額
  ├─ 材料費（領収書をスマホ撮影 → AIが工事番号に振り分け）
  ├─ 外注費（職人ごと・現場ごと）
  └─ 自社工数
      ↓
  工事別の粗利がリアルタイムで見える
      ↓
  「この工事種別は薄利」「この職人は原価が高い」が分かる
      ↓
  次の見積に反映
```

→ Googleスプレッドシート＋AIで構築可能。TKCと競合しない。月末に集計だけ渡す。
→ **副次効果：決算変更届の工事経歴書がここから生成できる。**

#### その他

| 領域 | 内容 |
|---|---|
| 証憑のデジタル化 | 現場でスマホ撮影 → Google Drive → AIが日付・金額・取引先・工事番号を抽出 |
| 請求書・注文書の作成 | 見積から自動生成 |
| 職人管理台帳 | 登録番号の有無、単価、契約形態を一元管理 |
| 電帳法対応 | フォルダ設計・検索要件の整備 |
| 入金消込 | 請求と入金の突合候補をAIが提示 |
| 母の作業の手順書化 | 前述 |

### 環境について（Chromebook）

- **今の環境（Chromebook + Google Drive + Web版Claude）で、上記はすべて実行可能**
- Google DriveへのAIからの**読み書き（作成・更新・共有）は可能**
- AI生成（動画・画像・文章・コード）は**すべてサーバー側で処理されるため、PC性能は品質に一切影響しない**
- PC性能が効くのは「動画編集の仕上げ」「Xcode等のローカル開発」のみ
- → **MacBook Pro等の購入判断は、実際に壁にぶつかってからでよい**
